## Задача 1: Добавить в таблицу "Наценка на объект" в маппинге данных застройщика

**Обоснование:** Застройщики часто применяют наценку (удорожание) к базовой стоимости квартиры, если клиент выбирает рассрочку вместо 100% оплаты. Эта наценка может быть выражена как в процентах, так и в фиксированной сумме. Для корректного расчета реальной стоимости и сравнения с рыночной ипотекой системе необходимо знать это значение.
1. [[4. Маппинг данных. Выгрузка условий от застройщика#^fdd613]Удорожание стоимости : процент + фикс]]
	_Подсказка для заполнения: Указывается, если застройщик добавляет к цене фиксированную сумму за использование рассрочки (например, +500 000 ₽ к договору). Если наценка только в %, заполняется поле 8.1._

# User Flow 
## Общая схема потока

```
[Вход на сайт] 
      ↓
[Геотаргетинг: автоопределение локации]
      ↓
[Шаг 1: Выбор цели И целевой группы]
      ↓
[Шаг 2: Бюджет (слайдер)]
      ↓
[Шаг 3: Специализированные фильтры (зависят от ЦГ)]
      ↓
[Шаг 4: Выдача результатов + карточки с уникальными условиями]
      ↓
[Шаг 5: Детальный просмотр + калькулятор]
      ↓
[Шаг 6: Сравнение сценариев]
      ↓
[Шаг 7: Конверсия]
```

##  Детализация по шагам 

###  Шаг 0. Геотаргетинг

**Действие системы:**
- Автоопределение локации (GPS + fallback на IP)
- Связь с полем `region_name`, `metro_stations`, `latitude`, `longitude` из `DeveloperOffers`
**Экран:**
> *«Показать квартиры рядом с вами? [Да / Выбрать другой район]»*
###  Шаг 1. Выбор цели И целевой группы

**Важное:** Вместо простого «Для жизни / Инвестиции» предлагаем **3 целевые группы** (из исследования):

**Экран:**
```
Выберите, кто вы:

👨‍👩‍👧 Молодая семья
   → Подберём с учётом детей, семейной ипотеки, инфраструктуры

💰 Инвестор
   → Рассчитаем доходность, срок окупаемости, ликвидность

👤 Индивидуальный покупатель
   → Гибкий подбор с калькулятором и сравнением сценариев
```

**Запись в БД:**
```sql
INSERT INTO UserSessions (session_id, target_group, geo_detected)
VALUES (uuid, 'family' | 'investor' | 'individual', geo_json)
```

### Шаг 2. Бюджет (слайдер)

**Экран:** Один слайдер — «Ваш совокупный бюджет»
- Диапазон: от 5 до 100 млн ₽
- Подсказка: *«Включает первоначальный взнос и стоимость квартиры»*

**Логика системы (из исследования):**
- На основе бюджета и среднего ПВ на рынке (20-30%) автоматически рассчитывается допустимый диапазон цен
- Пример: бюджет 50 млн ₽ → доступны квартиры до 40-42 млн ₽ при ПВ 15-20%

**Запись в БД:**
```sql
UPDATE UserSessions SET budget_total = 50000000 WHERE session_id = ?
```

###  Шаг 3. Специализированные фильтры (зависят от целевой группы)

**КЛЮЧЕВОЕ :** Фильтры меняются в зависимости от выбранной ЦГ
#### Для «Молодой семьи»:

**Фильтры:**
1. **Гео** (район / метро) — предзаполнено из геотаргетинга
2. **Количество комнат** (студия / 1 / 2 / 3+)
3. Специальные программы (чек-боксы из исследования):
   * ☑ Семейная ипотека (фильтр по `is_for_families = true`)
   - ☑ Дети до 7 лет (фильтр по программам для семей)
   - ☑ Беременным (фильтр по `is_for_pregnant = true`)
   - ☑ Материнский капитал
   - ☑ IT-ипотека (фильтр по `is_it_mortgage = true`)
1. **Инфраструктура** (чек-боксы):
   - ☑ Детский сад в пешей доступности
   - ☑ Школа рядом
   - ☑ Парк / зелёная зона

**Пример :** Если выбрано «Дети до 7 лет» → показываются ЖК с программами «Рассрочка для семейных» от ГК ФСК, ДСК-1

#### Для «Инвестора»:
**Фильтры:**
1. **Гео** (район / метро)
2. **Тип недвижимости** (студия / 1-комнатная — самые ликвидные)
3. **Инвестиционные параметры** (из исследования):
   - ☑ Минимальный ПВ (слайдер: от 10% до 50%)
   - ☑ Срок окупаемости (слайдер: до 5 / 7 / 10 лет)
   - ☑ Инвестиционный потенциал района (фильтр по динамике цен)
   - ☑ Квартиры для аренды (близость к деловым центрам, университетам)
4. **Тип рассрочки** (из исследования):
   - ☑ Беспроцентная (`is_interest_free = true`)
   - ☑ Отложенный платёж (`payment_type = 'deferred'`)
   - ☑ Ключи до оплаты (`has_key_early_release = true`)
5. Льготные программы:
   - ☑ IT-ипотека (`is_it_mortgage = true`)

**Пример из исследования:** Если выбрано «Минимальный ПВ до 20%» → показываются ЖК от ГК Эталон (ПВ 10%), Level Group (ПВ 30%)

---

#### Для «Индивидуального покупателя»:

**Фильтры:**
1. **Гео** (район / метро)
2. **Количество комнат**
3. **Тип рассрочки** (из исследования — классификация по привлекательности):
   - ☑ Беспроцентная рассрочка
   - ☑ С фиксированным платежом (`payment_type = 'fixed'`)
   - ☑ Ежемесячные / ежеквартальные платежи (`payment_type = 'monthly' | 'quarterly'`)
   - ☑ Отложенный платёж (`payment_type = 'deferred'`)
4. **Уникальные условия** (из исследования):
   - ☑ Переход на ипотеку (`can_switch_to_mortgage = true`)
   - ☑ Ключи до оплаты (`has_key_early_release = true`)
   - ☑ Trade-In
   - ☑ Материнский капитал
   - ☑ IT-ипотека (фильтр по `is_it_mortgage = true`)
1. **Срок рассрочки** (слайдер: от 6 мес до 5 лет)
2. **Минимальный ПВ** (слайдер: от 0% до 50%)

**Особенность:** Этот пользователь может сразу перейти к **калькулятору** (Шаг 5) без применения фильтров

###  Шаг 4. Выдача результатов

**Экран:** Сетка карточек ЖК (структура из исследования)

**Каждая карточка содержит:**
- Логотип застройщика + название ЖК (из `developer_name`, `project_name`)
- Цена, площадь, количество комнат (из `price_min`)
- Миникарта + ближайшие метро (из `region_name`, `metro_stations`)
- **Эмблемы уникальных условий** :
  -  «0%» (если `is_interest_free = true`)
  -  «Ключи до оплаты» (если `has_key_early_release = true`)
  -  «Беременным» (если `is_for_pregnant = true`)
  -  «Семейная» (если `is_for_families = true`)
  -  «Отложенный платёж» (если `payment_type = 'deferred'`)
- Краткое описание программы (из `discount_description`, `interest_rate_percent`)
  - Пример: *«Беспроцентная рассрочка на 9 мес»*
  - Пример: *«Скидка 32% + 14% годовых»*
- Кнопки: «Подробнее», «Сравнить», «В избранное»,
- Цена с ремонтом : 16 000 000 ₽ (перечёркнуто) 
	Базовая цена: 15 000 000 ₽  # ==именно по этой цене работает фильтры==
	С вашей программой: 13 200 000 ₽
	Ваша выгода: 1 800 000 ₽

**Панель фильтров сбоку** (динамическая, из исследования):
- Остается на экране, позволяя менять критерии без перезагрузки

###  Шаг 5. Детальный просмотр ЖК + Калькулятор

**Экран:**
1. **Галерея фото + планировки**
2. **Информационная панель:**
   - Название ЖК, застройщик, цена
   - Таблица с параметрами рассрочки (из `DeveloperOffers`):
     - ПВ: 20%
     - Срок: 9 мес
     - Ставка: 0%
     - Тип платежа: фиксированный
1. **Встроенный калькулятор** :
   - Слайдеры: ПВ (от 10% до 50%), срок (от 6 мес до 5 лет)
   - Мгновенный пересчёт ежемесячного платежа
   - **Сравнение с рыночной ипотекой** :
     - Автоматический расчет платежа по рыночной ипотеке (через API банков)
     - Визуализация выгоды: *«Ваша выгода: 1 800 000 ₽ по сравнению с рыночной ипотекой»*
4. **Карта** с расположением ЖК + ближайшие метро/инфраструктура
5. **Кнопки действия:**
   - «Сравнить» (добавить в таблицу сравнения)
   - «В избранное»
   - «Позвонить менеджеру»
   - «Записаться на просмотр»
   - «Написать в WhatsApp»

**Запись в БД:**
```sql
INSERT INTO UserViews (view_id, session_id, offer_id, action)
VALUES (uuid, session_id, offer_id, 'detailed_view')
```

### Шаг 6. Сравнение сценариев (из исследования)

**Экран:** Таблица сравнения (до 3-4 ЖК)

**Строки таблицы** (из исследования):
- Общая стоимость квартиры
- Размер первоначального взноса
- Ежемесячный платеж по рассрочке
- Общая переплата (если есть)
- Итоговая сумма к оплате
- Возможный ежемесячный платеж по рыночной ипотеке

**Визуализация:**
- Графики платежей по месяцам
- Сравнительная диаграмма выгоды

**Пример из исследования:**
Пользователь сравнивает:
- Сценарий А: Рассрочка 0% на 12 мес, ПВ 20% (Level Group)
- Сценарий Б: Рассрочка 7% годовых на 18 мес, ПВ 30%
- Сценарий В: Рыночная ипотека по ставке 19% с ПВ 30%

Система показывает, какой вариант дешевле в долгосрочной перспективе

###  Шаг 7. Конверсия

**Варианты действий** (из исследования):
1. **«Позвонить менеджеру»** → клик по телефону застройщика
2. **«Написать в МАКС»** → открытие чата
3. **«Записаться на просмотр»** → форма с датой/временем
4. **«Забронировать»** → форма с именем + телефоном
5. **«Подписаться на уведомления»** → пользователь указывает предпочтения (район, площадь, бюджет) и получает push-уведомления о новых предложениях

**Важно:** Конверсия происходит **без регистрации** , чтобы не создавать барьеров

**Запись в БД:**
```sql
INSERT INTO UserConversions (conversion_id, session_id, offer_id, conversion_type)
VALUES (uuid, session_id, offer_id, 'call' | 'whatsapp' | 'visit' | 'lead' | 'subscription')
```

##  Ключевые точки принятия решений

| # | Точка | Условие | Действие |
|---|-------|---------|----------|
| **D1** | После входа | Есть GPS-разрешение? | YES → точная геолокация; NO → IP fallback |
| **D2** | Шаг 1 | Выбрана ЦГ? | YES → спец. фильтры; NO → универсальные |
| **D3** | Шаг 3 | Найдены совпадения? | YES → выдача; NO → предложение расширить критерии |
| **D4** | Шаг 5 | Использует калькулятор? | YES → API /calculate; NO → просто просмотр |
| **D5** | Шаг 6 | 2+ объекта в сравнении? | YES → таблица сравнения; NO → продолжить просмотр |
| **D6** | Шаг 7 | Выбран способ связи? | YES → конверсия; NO → подписка на уведомления |
| **D7** | Ветка «Инвестор» | Указана арендная ставка? | YES → расчёт ROI; NO → только базовые параметры |
| **D8** | Ветка «Семья» | Есть дети до 7 лет? | YES → фильтр is_for_families; NO → общие программы |
