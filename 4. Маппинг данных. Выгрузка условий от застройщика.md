# Маппинг данных: Выгрузка условий от застройщика
## Цель
Создать **единый формат выгрузки** (Excel/CSV/JSON), который застройщик может заполнить за 15-20 минут, а система автоматически импортирует в базу `DeveloperOffers`.

### ГРУППА 7: Фид Яндекс.Недвижимость (автозагрузка объектов)

Назначение:
Если застройщик передаёт URL фида в формате Яндекс.Недвижимости, система может автоматически получать из него часть данных по объектам: тип недвижимости, адрес, метро, цену, площадь, комнаты, изображения, описание и другие характеристики.

Важно:
Фид Яндекс.Недвижимости закрывает объектовые данные по квартирам/помещениям, но не заменяет финансовые условия рассрочки. Такие параметры, как минимальный первоначальный взнос, срок рассрочки, ставка, тип платежей и уникальные условия программы, продолжают передаваться через основную выгрузку застройщика.

#### 7.11. Правила обработки фида

1. Каждый тег `<offer>` обрабатывается как отдельный объект.
2. Уникальный ключ объекта: `external_offer_id` из атрибута `internal-id`.
3. Если в фиде несколько объектов, система может:
    - обновлять минимальную цену проекта;
    - собирать доступные типы недвижимости;
    - собирать список метро;
    - обновлять изображения и описания.
4. Если обязательные поля объекта отсутствуют, такой объект пропускается или помечается как требующий ручного разбора.
5. Минимально обязательными для обработки объекта считаются:
    - `offer/@internal-id`;
    - `price/value`;
    - `location/country` или `location/locality-name` или `location/address`;
    - `property-type`;
    - `category`.
6. Повторяющиеся теги, например `image` и `room-space`, сохраняются как массивы.
7. Если валюта указана как `RUR`, рекомендуется нормализовать её к `RUB`.
8. Если координаты отсутствуют, система может получить их через API геокодирования по адресу.
9. Финансовые условия рассрочки из фида не берутся. Они должны быть заполнены застройщиком в основной выгрузке:
    - `min_down_payment_percent`;
    - `term_months`;
    - `interest_rate_percent`;
    - `payment_type`;
    - `is_interest_free`;
    - `discount_description`;
    - уникальные условия.

```
│                    ПРОЦЕСС ИМПОРТА ДАННЫХ                       │
└─────────────────────────────────────────────────────────────────┘

[1] ЗАСТРОЙЩИК заполняет Excel/CSV по шаблону
    ↓
[2] СИСТЕМА валидирует данные:
    • Проверка обязательных полей
    • Проверка форматов (числа, даты)
    • Проверка логики (ПВ ≤ 100%, срок > 0)
    ↓
[3] АВТОМАТИЧЕСКОЕ ОБОГАЩЕНИЕ:
    • Если нет координат → подтягиваем из API Яндекс.Карт
    • Если нет метро → определяем по координатам
    • Если ставка = 0% → автоматически is_interest_free = true
	• Если указан `feed_url` → запуск парсера XML → извлечение объектов и _url → система скачивает XML и парсит данные по разделу «ГРУППА 7: Фид Яндекс.Недвижимость»  
    ↓
[4] МАППИНГ в структуру БД:
    • Excel колонки → поля таблицы DeveloperOffers
    • Создание UUID для каждого offer_id
    • Установка created_at, updated_at
    ↓
[5] ЗАПИСЬ в БД:
    • INSERT INTO DeveloperOffers (...)
    • Индексация для быстрого поиска
    ↓
[6] ПРОВЕРКА И МОДЕРАЦИЯ:
    • Автоматическая проверка на дубликаты
    • Флаг is_active = true
    ↓
[7] ДОСТУПНО ДЛЯ ПОЛЬЗОВАТЕЛЕЙ:
    • Появляется в выдаче поиска
    • Доступно через API /api/v1/offers
```
## Визуальная схема маппинга

```
┌─────────────────────────────────────────────────────────────────┐
│                    ФОРМАТ ВЫГРУЗКИ (EXCEL)                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ГРУППА 1: БАЗОВАЯ ИНФОРМАЦИЯ                                   │
│  ├─ Застройщик ──────────────────┐                              │
│  ├─ Проект (ЖК) ─────────────────┤ → developer_name             │
│  ├─ URL фида (Я.Недвижимость) ───┤ → feed_url (авто-парсинг XML)│
│  └─ Минимальная цена ────────────┘ → property_type, price_min   │
│                                                                 │
│   ГРУППА 2: ФИНАНСОВЫЕ УСЛОВИЯ                                  │
│  ├─ Первоначальный взнос (%) ────┐                              │
│  ├─ Срок рассрочки (мес) ────────┤ → min_down_payment_percent   │
│  ├─ Ставка годовых (%) ──────────┤ → term_months                │
│  ├─ Беспроцентная? ──────────────┤ → interest_rate_percent      │
│  └─ Описание скидки ─────────────┘ → is_interest_free           │
│  └─ Наценка ─────────────────────┘ → price_markup_percent       │
│  └─ Фикс увеличение цены ────────┘ → object_markup_fixed        │
│                                                                 │
│   ГРУППА 3: ТИП ПРОГРАММЫ                                       │
│  └─ Тип графика платежей ──────── → payment_type                │
│     (fixed / monthly / quarterly / deferred)                    │
│                                                                 │
│   ГРУППА 4: УНИКАЛЬНЫЕ УСЛОВИЯ                                  │
│  ├─ Ключи до оплаты? ────────────→ has_key_early_release        │
│  ├─ Для беременных? ─────────────→ is_for_pregnant              │
│  ├─ Для семей? ──────────────────→ is_for_families              │
│  ├─ Переход на ипотеку? ─────────→ can_switch_to_mortgage       │
│  └─ IT-ипотека? ─────────────────→ is_it_mortgage               │
│                                                                 │
│   ГРУППА 5: ГЕОГРАФИЯ                                           │
│  ├─ Район ───────────────────────┐                              │
│  ├─ Метро (через запятую) ───────┤ → region_name                │
│  ├─ Широта ──────────────────────┤ → metro_stations             │
│  └─ Долгота ─────────────────────┘ → latitude, longitude        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                    ┌─────────────────┐
                    │  СИСТЕМА ИМПОРТА │
                    │  (автовалидация) │
                    └────────┬────────┘
                             ↓
                    ┌─────────────────┐
                    │   БД БАЗА       │
                    │ DeveloperOffers │
                    └─────────────────┘
```
